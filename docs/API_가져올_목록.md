# API 가져올 목록 (2026-11-26 확인)

이용 조건은 공공데이터포털(data.go.kr) 상세 페이지에서 2026-11-26에 직접 확인했다.
공모 요강·참가 서약서의 탈락·취소 사유에 맞춰 각 API마다 **쓰는 범위**와 **쓰지 않는 범위**를 정했다.

## 2. 가져오지 않는 것과 이유

| 자료 | 이유 |
|---|---|
| 올림픽공원 홈페이지의 공연 일정·공연장 도면·좌석배치도 | 공공누리 표시가 없다. 기관 저작권정책상 사전 협의가 필요하다 → 링크만 건다 |
| 공연 포스터·행사 사진(대관정보·공지사항 첨부 포함) | 기획사·사진가 등 제3자 저작물이고 초상권 문제도 있다 |
| 공지사항의 본문·첨부파일 | 첨부에 제3자 자료가 섞일 수 있다 → 제목·날짜·링크만 쓴다 |
| 유실물 정보 | 서비스 목적과 관계없다. 개인 소지품 정보라 쓰지 않는다 |
| 올팍소식·갤러리·장미 개화 | 서비스 목적과 관계없다. 사진은 저작물이다 |
| 지도 앱 SDK(네이버·카카오 지도 화면 넣기) | 각사 약관과 키가 필요하다 → 길찾기 링크로만 연결한다(지금 방식 유지) |
| 지하철 혼잡 자료 | 마감 전 검증 시간이 부족해 이번에는 넣지 않는다 → 지도 앱 링크로 안내한다 |

## 3. 저작권·탈락 사유별로 지킬 규칙

| 원문 조항 | 위험 | 지킬 규칙 |
|---|---|---|
| 요강: 기관 공공데이터 1종 이상 활용 | 없음 | 새 API 4종 중 3종이 한국체육산업개발 데이터다. 기상청은 '타 기관 공동활용'으로 적는다 |
| 서약 4항: 타인 저작권 침해 시 취소 | 포스터·사진·홈페이지 글을 가져오는 것 | 위 2절 목록은 수집 단계에서부터 받지 않는다. 텍스트 항목(행사명·장소·일시)만 저장한다 |
| 공공누리 제1유형 | 출처 누락 | 화면 하단과 README에 "출처: 기상청, 한국체육산업개발주식회사, 공공데이터포털"을 쓴다 |
| 서약 2항·요강: 허위 기재 시 취소 | 대관정보로 바꾼 뒤 숫자가 달라지는데 기획서에 예전 숫자를 쓰는 것 | 기획서 숫자는 마지막으로 돌린 분석 결과 파일에서만 옮긴다. 예측은 "과거 기록으로 본 예상"이라고 쓴다 |
| 개인정보 보호 | 입출차의 차량번호, 대관 신청자·연락처 같은 항목 | 응답에 이런 항목이 있으면 수집 단계에서 버리고 저장·공개하지 않는다. 쓰는 항목만 골라 남긴다 |
| 기상법(예보는 기상청 등만 발표) | 앱이 스스로 날씨를 예측하는 것처럼 보이는 것 | 기상청 예보를 출처와 함께 그대로 보여 준다. "비 예보가 있어 보정했어요"까지만 쓰고 날씨를 직접 예측하는 문구는 쓰지 않는다 |
| 인증키 보안 | 공개 저장소·웹 페이지에 키가 노출되는 것 | 키는 GitHub Actions 비밀값으로만 쓴다. Actions가 받아 JSON으로 저장하고, 웹은 그 JSON만 읽는다 |
| 운영 협조(서약 6항, 2028년까지) | 개발 키는 운영 단계에서 막힐 수 있다 | 수상하면 입출차·공지사항은 운영 단계 활용신청(심의승인)을 낸다 |

## 4. 할 일

1. **신청(직접):**
   - 문화데이터광장에서 대관정보(id=353), 입출차정보(전체구역)(id=659)를 신청한다. 선택으로 공지사항(id=116)도 신청한다.
   - 공공데이터포털에서 기상청 단기예보를 신청한다.
   - 공공데이터포털에 개발단계 자동승인으로 표시돼 있어 바로 승인될 가능성이 높다.
2. **비밀값 등록(직접):** 저장소 Settings → Secrets and variables → Actions에 키를 넣는다.
   - `KCISA_RENTAL_KEY`(대관정보)
   - `KCISA_PARKING_ZONE_KEY`(전체구역)
   - `KMA_KEY`(기상청)
   - 키가 하나로 통합돼 있으면 같은 값을 넣는다.
3. **수집·반영(제가):**
   - 응답 항목을 보고 쓰는 항목만 고르는 목록을 확정한다.
   - 수집 워크플로를 만든다.
   - 다음 기능을 붙인다: 대관정보로 날짜별 행사·공연장 표시, 공연장별 분석, 비 예보 자동 보정.
   - README·기획안의 데이터 표를 갱신한다.
4. **기한:** 11/27(금)까지 키가 오면 반영한다. 키가 오지 않으면 기획서에 "추가 연동 계획"으로만 적는다.
