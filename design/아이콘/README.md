# 앱 아이콘

원본은 SVG 하나다. 크기별 PNG는 원본에서 뽑는다. 손으로 PNG를 고치지 않는다.

```bash
python tools/icon_svg.py      # 원본 SVG: design/아이콘/icon_*.svg, web/app/icons/{icon,icon-full,favicon}.svg
node tools/export_icons.js    # PNG: web/app/icons/*.png
```

## 쓰는 시안: A. 한 줄
비교는 `시안비교.png`에 있다. 다른 시안으로 바꾸려면 `tools/icon_svg.py`의 `CHOSEN`을 고치고 위 두 줄을 다시 실행한다.

## 규칙 (토큰)
| 항목 | 값 | 이유 |
|---|---|---|
| 바탕 | 위 `#1FC386` → 가운데 `#00A86B`(브랜드) → 아래 `#008F5A` 세로 명암 | 평면 단색보다 깊이가 생긴다. 가운데가 화면의 `--brand`와 같다 |
| 위쪽 빛 | 흰색 16% → 0% 원형 | 홈 화면에서 아이콘이 떠 보이게 한다. 더 세게 하면 2010년대 광택처럼 보인다 |
| 글자 | DBT Sans(Pretendard 기반, OFL) 윤곽선을 벡터로 옮김, 굵기 680, 흰색 | 화면 글꼴과 같은 가족이다 |
| 자간 | 글꼴 칸이 아니라 잉크 기준으로 같은 간격(0.06em) | 한글 칸을 그대로 쓰면 '빌때'처럼 붙거나 '덜붐'처럼 벌어진다 |
| 폭 | 글줄이 아이콘 폭의 64% | 안드로이드가 원으로 잘라도(안전 영역 80%) 남는다 |
| 세로 위치 | 무게중심 48.5% (정중앙보다 살짝 위) | 한글은 받침 때문에 아래가 무거워 정중앙이면 처져 보인다 |
| 그림자 | 아래 10px, 흐림 14px, 진초록 22% | 글자가 바탕에서 떨어져 보인다. 이보다 진하면 싸 보인다 |
| 모서리 | 원본은 모서리 없음. 브라우저·설치 아이콘만 반지름 22.37% | 아이폰·안드로이드는 자기 모양으로 자른다. 모서리를 미리 넣으면 이중 모서리가 생긴다 |
| 작은 크기(탭 32px) | '덜' 한 글자, 굵기 820, 그림자 없음 | 32px에서 네 글자는 읽히지 않는다 |

## 하지 말 것
- 이모지·외부 아이콘·사진을 넣지 않는다(라이선스와 일관성).
- 글꼴을 바꾸지 않는다. 바꾸면 글꼴 라이선스부터 확인한다.
- 아이폰 아이콘(apple-touch-icon)에 투명 바탕을 쓰지 않는다. 검게 채워진다.
