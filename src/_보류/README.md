# 보류한 코드 (2026-11-17)

아래 코드는 **올림픽공원 홈페이지 자료**를 씁니다. 기관 저작권정책상 공공누리 표시가 없는 홈페이지 자료는
"담당자와 사전에 협의한 이후에 이용"해야 하므로, 허락을 받기 전까지 파이프라인과 결과물에서 뺐습니다.

| 파일 | 쓰는 홈페이지 자료 | 하던 일 |
|---|---|---|
| `fetch_events.py` | 공연/행사 일정 상세 페이지 | 2025년 공연의 공연장·시작 시각·가까운 입구/주차장 수집 |
| `match_venue.py` | (위 결과) | 2025 연계 데이터 공연명에 공연장·시작 시각 매칭 |
| `metrics_venue.py` | (위 결과) | 공연장별 '시작 기준' 혼잡 곡선 |
| `build_olympichall_3d.py` | 올림픽홀 공연장 안내의 평면도·단면도 | 올림픽홀 3D 자체 제작 (PyMuPDF 사용: AGPL 라이선스 주의) |

허락을 받으면: 파일을 `src/` 로 되돌리고, `run_all.py` 에 단계를 다시 추가한 뒤, 받은 회신 내용을 기획서 출처에 적는다.
